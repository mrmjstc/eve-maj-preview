Travel Mode

profile

Detects when a tracked character falls behind while the rest of the group jumps together, and fires a notification. Runs automatically once enabled below - no manual start/stop needed. Border color, duration, and TTS for the alert are configured above under "Left Behind".

How long a straggler has to jump into the group's current system before being flagged as left behind

How many characters must already share a system before stragglers there count as "left behind" - avoids false alerts from a single character jumping around alone

Log Monitoring

profile

Watches EVE's chatlog and gamelog files to drive the DPS overlay, mining overlay, and system-location display. In EVE, enable Esc > Chat Channel Settings > Log chat to file so logs get written to disk.

Polling & Performance

How often to check each log file for new lines. Lower is more responsive but uses more CPU; clamped to 0.1-5s.

Consecutive quiet polls before a log is considered idle and polled less often to save CPU. New activity resets it to full speed.

Cap on how much idle logs slow down (e.g. 8x = checked 8x less often). Higher saves CPU for AFK characters but delays detecting new activity.
