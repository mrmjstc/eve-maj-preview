EVE-Maj Preview

Log Monitoring

Watches EVE's chatlog and gamelog files to drive the DPS overlay, mining overlay, and system-location display. In EVE, enable Esc > Chat Channel Settings > Log chat to file so logs get written to disk.

Log Directories

Folder EVE writes chat channel logs to (used for local/say chat parsing). Defaults to Documents\EVE\logs\Chatlogs.

Folder EVE writes combat/mining/system gamelogs to. Defaults to Documents\EVE\logs\Gamelogs.

Polling & Performance

How often to check each log file for new lines. Lower is more responsive but uses more CPU; clamped to 0.1-5s.

Consecutive quiet polls before a log is considered idle and polled less often to save CPU. New activity resets it to full speed.

Cap on how much idle logs slow down (e.g. 8x = checked 8x less often). Higher saves CPU for AFK characters but delays detecting new activity.
