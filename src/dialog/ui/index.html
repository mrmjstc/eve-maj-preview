EVE-Maj Preview

A modern, lightweight window preview tool for EVE Online, built with Zig.

Version: 0.0.2

Repository: github.com/mrmjstc/eve-maj-preview

Discord: mjstc

System Colors

profile

Define custom colors for specific solar systems. These take priority over Unique System Colors and the default color. Separate names with commas; * matches any text, ? any character, # any digit (e.g. J######).

Interaction

profile

Mouse behavior for repositioning and activating thumbnails, including when to activate the EVE client window on left-click.

Thumbnails ignore all mouse input and let clicks/drags pass through to whatever is behind them; disables click-to-focus, exclusion toggling, and dragging.

Mouse Up avoids accidental drags from a quick click.

Mouse cursor shown while hovering a thumbnail.

Auto-Minimize

profile

Minimizes an EVE client window after it's been unfocused for the configured delay.

Exempts whichever client you focused most recently, even past the delay.

How long a client can sit unfocused before it's minimized.

No Animation minimizes instantly; Original Animation keeps Windows' native minimize effect.

Character Exclusion

profile

Controls Shift+Click exclusion of characters from hotkey cycling.

Minimizes immediately on exclusion, not on the Auto-Minimize delay above.

20%

Window Position

profile

Saves each character's real EVE client window position, restored via the Move to Saved Positions hotkey or automatically on login. Set All copies the selected window's current position to every character; Clear All removes every saved position.

Moves a client to its saved position when its character logs in.

Moves clients already logged in when the app launches.

How often a moved client's position is re-checked; EVE can shift its own window while loading.

How many times to re-check and re-apply the position after a move. 0 disables re-checking.

Ultra Potato Mode

eve settings

Forces EVE Online's heaviest graphics settings (shaders, shadows, textures, reflections, post-processing, cloth, ambient occlusion, volumetrics) to their lowest quality. Close all EVE clients first - the client overwrites these files on exit. A .bak backup of each file is made before its first edit.

Travel Mode

Log Monitoring

profile

Watches EVE's chatlog and gamelog files to drive the DPS overlay, mining overlay, and system-location display. In EVE, enable Esc > Chat Channel Settings > Log chat to file so logs get written to disk.

Caps how much slower an idle file's interval can back off to; resets to 1x as soon as it has new lines again.
